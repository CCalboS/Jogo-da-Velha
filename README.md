# ❌ Jogo da Velha

Uma implementação do clássico **Jogo da Velha** desenvolvida em **C# utilizando o Visual Studio 2022**.

Este é um projeto consideravelmente antigo, desenvolvido durante uma fase inicial dos meus estudos em C#..

Infelizmente, os **arquivos-fonte originais não estão mais disponíveis**, portanto este repositório contém apenas o executável do jogo.

O projeto faz parte do meu histórico de aprendizado e representa uma das primeiras experiências que tive desenvolvendo jogos e aplicando lógica de programação na prática.

## 🎯 Objetivos do projeto

* Praticar C# e lógica de programação;
* Implementar as regras do Jogo da Velha;
* Trabalhar com posições e estados dos elementos do jogo;
* Criar uma aplicação funcional partindo do zero;
* Experimentar o desenvolvimento de jogos durante os primeiros estudos.

## 📦 Arquivos

O código-fonte original infelizmente foi perdido. Por esse motivo, está disponível neste repositório apenas o **executável** do jogo.

> **Nem todo projeto antigo sobrevive inteiro. Às vezes, o que resta é apenas o programa funcionando — mas até isso já conta uma história.**
